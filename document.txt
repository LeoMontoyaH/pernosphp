1. DESCRIPCIÓN GENERAL
--------------------------------------------------
Proyecto web e-commerce desarrollado para "PERNOSCOL", una empresa 
especializada en soluciones de fijación, tornillería industrial y herramientas 
en Colombia. Cuenta con catálogo dinámico conectado a base de datos MySQL, 
carrito de compras interactivo y un sistema completo de autenticación de usuarios.

2. TECNOLOGÍAS UTILIZADAS
--------------------------------------------------
- Frontend: HTML5, CSS3 (Estilos personalizados sin frameworks externos), JavaScript (ES6+).
- Backend: PHP 8.x.
- Base de Datos: MySQL (Gestionada mediante phpMyAdmin en entorno local XAMPP).
- Iconos y Fuentes: FontAwesome 6.4.0, Segoe UI.

4. ESTRUCTURA DE LA BASE DE DATOS (pernoscol_db)
--------------------------------------------------
Ejecuta el siguiente script SQL en phpMyAdmin para configurar las tablas:

CREATE DATABASE IF NOT EXISTS pernoscol_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE pernoscol_db;

-- Tabla de Usuarios
CREATE TABLE IF NOT EXISTS usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla de Productos Destacados
CREATE TABLE IF NOT EXISTS productos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    descripcion TEXT NOT NULL,
    precio DECIMAL(10,2) NOT NULL,
    imagen VARCHAR(255) NOT NULL,
    rating INT DEFAULT 5
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

5. INSTRUCCIONES DE EJECUCIÓN EN XAMPP
--------------------------------------------------
1. Iniciar los servicios de Apache y MySQL en el panel de control de XAMPP.
2. Copiar la carpeta completa 'pernoscol' dentro del directorio C:\xampp\htdocs\.
3. Abrir phpMyAdmin (http://localhost/phpmyadmin/), crear una base de datos o importar el script SQL anterior.
4. Abrir el navegador e ingresar a la URL: http://localhost/pernoscol/index.php
